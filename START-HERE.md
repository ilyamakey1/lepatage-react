## 🎯 Как запустить на вашем сервере

### Шаг 1: Подготовьте сервер
```bash
# Любой VPS с Ubuntu 20.04+
# Минимум: 2GB RAM, 20GB диск
# Рекомендуется: 4GB RAM, 50GB диск
```

### Шаг 2: Загрузите проект
```bash
# Скопируйте весь проект на сервер
scp -r lepatage-react/ user@your-server:/var/www/
```

### Шаг 3: Запустите автоматическое развертывание
```bash
cd /var/www/lepatage-react
chmod +x deploy.sh
./deploy.sh
```

### Шаг 4: Настройте домен
- Укажите ваш домен в `.env` файле
- Настройте DNS записи на ваш сервер IP

## 🌐 После развертывания

## 🔧 Управление сайтом

### Обновление контента
```bash
# Обновить код
./update.sh

# Посмотреть логи
docker-compose logs -f

# Перезапустить сервисы
docker-compose restart
```

### Резервное копирование
```bash
# Создать бэкап вручную
/usr/local/bin/lepatage-backup.sh

# Автоматические бэкапы настроены на каждый день в 2:00
```
