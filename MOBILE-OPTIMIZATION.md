# 📱 Мобильная оптимизация L'Épatage

## ✅ Выполненные улучшения

### 1. Header и навигация
- **Мобильное меню**: Полнофункциональное выдвижное меню с поиском
- **Адаптивные иконки**: Размеры иконок адаптированы для мобильных
- **Улучшенная кнопка меню**: Анимированная иконка гамбургера/крестика
- **Поиск в мобильном меню**: Встроенный поиск товаров

### 2. Главная страница (ОБНОВЛЕНО)
- **Hero секция с текстом и CTA**: Полностью переработанная hero-секция с градиентом, текстом и кнопками призыва к действию
- **Мобильные кнопки**: Две CTA кнопки (Каталог и Индивидуальный заказ) с иконками, оптимизированы для касания
- **Оптимальные высоты**: Hero 85vh на мобильных, видео/фото секции 50vh, галерея 45vh
- **Блоки изображений**: Адаптивные высоты с плавными переходами (h-[45vh], h-[50vh])
- **Ценовые плашки**: Компактный дизайн с backdrop-blur эффектом и улучшенными отступами
- **Продуктовая сетка**: 2 колонки на мобильных (4 товара), 2 на планшетах, 3 на десктопе
- **Полноширинные кнопки**: CTA кнопки растягиваются на всю ширину на мобильных (до 640px)
- **Улучшенная типографика**: Адаптивные размеры текста для всех экранов
- **Hover эффекты**: Плавные переходы и масштабирование на галерейных изображениях

### 3. Страница товара
- **Свайп-жесты**: Переключение между изображениями свайпом
- **Мобильная навигация**: Точки для переключения изображений
- **Счетчик изображений**: Показ текущего изображения
- **Адаптивные размеры**: Оптимизированные отступы и размеры текста
- **Улучшенная кнопка "Назад"**: Компактная версия для мобильных

### 4. Каталог товаров
- **Адаптивная сетка**: 1 колонка на мобильных, 2 на планшетах
- **Оптимизированные отступы**: Уменьшенные промежутки между товарами
- **Мобильные карточки**: Компактные размеры текста и иконок

### 5. Форма индивидуального заказа
- **Мобильный прогресс-бар**: Линейный индикатор вместо кругового
- **Адаптивные поля**: Оптимизированные размеры и отступы
- **Улучшенная навигация**: Кнопки адаптированы для мобильных

### 6. Админ панель
- **Компактные табы**: Сокращенные названия на мобильных
- **Адаптивная навигация**: Перенос табов на новую строку
- **Мобильные размеры**: Оптимизированные отступы и размеры

### 7. Карточки товаров
- **Адаптивные размеры**: Компактные версии для мобильных
- **Оптимизированные иконки**: Меньшие размеры на мобильных
- **Улучшенные отступы**: Адаптивные промежутки

## 📊 Тестирование

### Автоматическое тестирование
```bash
./test-mobile.sh
```

### Ручное тестирование
1. Откройте сайт в браузере
2. Включите режим разработчика (F12)
3. Выберите мобильное устройство
4. Проверьте все страницы и функции

### Рекомендуемые устройства для тестирования

- iPhone 12 Pro (390px)
- Samsung Galaxy S20 (360px)
- iPad (768px)

## 🎨 Дизайн-система

### Breakpoints
- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px

### Размеры текста
- Mobile: text-sm, text-base
- Tablet: text-base, text-lg
- Desktop: text-lg, text-xl

### Отступы
- Mobile: p-3, p-4
- Tablet: p-4, p-6
- Desktop: p-6, p-8
