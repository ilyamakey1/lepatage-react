# Сайт не открывается — что проверить

## 1. Запущены ли серверы?

В терминале должны быть запущены **два** процесса:
- backend (порт 3001)
- frontend (порт 5173)

**Как запустить одной командой:**

```bash
cd "/Users/ila/Desktop/lepatage основа/lepatage-react"
./start-dev.sh
```

Не закрывайте окно терминала — пока скрипт работает, сайт доступен.

**Правильный адрес сайта:** http://localhost:5173 (именно 5173, не 3001).

---

## 2. Проверка вручную

Откройте **новый** терминал и выполните:

```bash
# Проверить, занят ли порт 5173 (должен быть занят, если frontend запущен)
lsof -i :5173

# Проверить порт 3001 (backend)
lsof -i :3001
```

Если оба порта **заняты** — серверы работают. Откройте в браузере: **http://localhost:5173**

Если порты **свободны** — серверы не запущены. Запустите снова:

```bash
cd "/Users/ila/Desktop/lepatage основа/lepatage-react"
npm run server
```

Во **втором** терминале:

```bash
cd "/Users/ila/Desktop/lepatage основа/lepatage-react"
npm run dev
```

После появления в консоли строки вроде `Local: http://localhost:5173/` откройте в браузере: **http://localhost:5173**

---

## 3. Что именно не работает?

| Ситуация | Что делать |
|----------|------------|
| Страница «Не удается получить доступ» / «Сайт не отвечает» | Серверы не запущены или упали. Запустите `./start-dev.sh` и не закрывайте терминал. |
| Белая страница | Откройте DevTools (F12) → вкладка Console. Скопируйте текст ошибок и проверьте их. |
| Ошибка «Подключение отклонено» | Убедитесь, что открываете **http://localhost:5173** (не 3001, не https). |
| Долго грузится и потом ошибка | Проверьте, что backend на 3001 запущен (`npm run server` в отдельном терминале). |

## 5. Если всё равно не открывается

- Попробуйте другой браузер (Chrome, Safari, Firefox).
- Попробуйте адрес: **http://127.0.0.1:5173**
- Перезапустите компьютер и снова запустите `./start-dev.sh` из папки проекта.
