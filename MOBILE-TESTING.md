# Тестирование мобильной версии сайта L'Épatage

## Способы тестирования мобильной версии

### 1. **DevTools браузера (Рекомендуется для разработки)**

#### Chrome DevTools:
1. Откройте сайт в Chrome
2. Нажмите `F12` или правой кнопкой → "Просмотреть код"
3. Нажмите на иконку мобильного устройства (Toggle device toolbar) или `Ctrl+Shift+M`
4. Выберите нужное разрешение из выпадающего списка:
   - iPhone SE (375x667)
   - iPhone 12 Pro (390x844)
   - iPhone 12 Pro Max (428x926)
   - Samsung Galaxy S20 (360x800)
   - iPad (768x1024)
   - Или задайте свое разрешение

#### Firefox DevTools:
1. Откройте сайт в Firefox
2. Нажмите `F12` или правой кнопкой → "Просмотреть код"
3. Нажмите на иконку мобильного устройства
4. Выберите разрешение или задайте свое

### 2. **Локальное тестирование на реальном мобильном устройстве**

#### Шаг 1: Запуск сайта локально
```bash
# В терминале в папке проекта
npm run dev
# или
yarn dev
```

#### Шаг 2: Узнать IP адрес компьютера
```bash
# macOS/Linux
ifconfig | grep "inet " | grep -v 127.0.0.1

# Windows
ipconfig | findstr "IPv4"
```

#### Шаг 3: Открыть на мобильном устройстве
- Убедитесь, что компьютер и мобильное устройство в одной Wi-Fi сети
- Откройте в браузере мобильного устройства: `http://[IP-адрес]:[порт]`
- Например: `http://192.168.1.100:5173`

### 3. **Онлайн инструменты для тестирования**

#### Responsively App:
- Скачайте [Responsively App](https://responsively.app/)
- Откройте сайт в приложении
- Просматривайте все брейкпоинты одновременно

#### BrowserStack:
- [BrowserStack](https://www.browserstack.com/) - тестирование на реальных устройствах
- [BrowserStack Live](https://www.browserstack.com/live) - бесплатно для тестирования

### 4. **Проверка основных элементов мобильной версии**

#### ✅ Обязательные проверки:
- [ ] Адаптивное меню (гамбургер меню)
- [ ] Корректные размеры шрифтов на маленьких экранах
- [ ] Правильное отображение изображений
- [ ] Работающие кнопки и ссылки
- [ ] Корректные отступы и поля
- [ ] Работающее видео (автовоспроизведение, зацикливание)

- [ ] Корректная работа форм

#### 📱 Брейкпоинты для проверки:
- **Mobile S**: 320px - 480px
- **Mobile M**: 481px - 768px  
- **Tablet**: 769px - 1024px
- **Desktop**: 1025px+

### 5. **Проверка производительности мобильной версии**

#### Lighthouse Audit:
1. Откройте DevTools → вкладка "Lighthouse"
2. Выберите "Mobile" и нужные категории
3. Нажмите "Generate report"
4. Проверьте:
   - Performance (производительность)
   - Accessibility (доступность)
   - Best Practices (лучшие практики)
   - SEO

#### Core Web Vitals:
- **LCP** (Largest Contentful Paint) < 2.5s
- **FID** (First Input Delay) < 100ms
- **CLS** (Cumulative Layout Shift) < 0.1

### 8. **Автоматизированное тестирование**

#### Playwright (рекомендуется):
```bash
# Установка
npm install -D @playwright/test

# Создание тестов
npx playwright codegen --target=playwright-test

# Запуск тестов
npx playwright test
```

#### Cypress:
```bash
# Установка
npm install -D cypress

# Запуск
npx cypress open
```

## Решение частых проблем

### Видео не воспроизводится на мобильных:
- Добавьте атрибут `playsInline`
- Убедитесь, что видео `muted`
- Проверьте формат видео (MP4 рекомендуется)

### Проблемы с производительностью:
- Оптимизируйте изображения
- Используйте lazy loading
- Минимизируйте JavaScript бандл

### Проблемы с отображением:
- Проверьте CSS медиа-запросы
- Убедитесь в корректности Tailwind классов
- Проверьте viewport meta тег

## Контакты для поддержки

При возникновении проблем с мобильной версией:
1. Проверьте консоль браузера на ошибки
2. Убедитесь в корректности HTML разметки
3. Проверьте CSS стили для мобильных устройств
4. Протестируйте на разных устройствах и браузерах
