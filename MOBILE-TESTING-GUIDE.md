# 📱 Руководство по тестированию мобильной версии L'Épatage

## 🚀 Быстрый старт

### 1. Запуск серверов
```bash
# Запуск бэкенд сервера
npm run server

# В новом терминале - запуск фронтенда
npm run dev
```

### 2. Автоматическое тестирование
```bash
./test-mobile.sh
```

## 🔍 Ручное тестирование в браузере

### Шаг 1: Откройте инструменты разработчика
1. Откройте http://localhost:5173 в Chrome или Firefox
2. Нажмите F12 или Ctrl+Shift+I (Cmd+Opt+I на Mac)
3. Нажмите на иконку мобильного устройства 📱

### Шаг 2: Выберите устройство для тестирования
Рекомендуемые устройства:
- **iPhone SE** (375×667) - маленький экран
- **iPhone 12 Pro** (390×844) - современный iPhone
- **Samsung Galaxy S20** (360×800) - Android
- **iPad** (768×1024) - планшет

### Шаг 3: Тестируйте каждую страницу

## 🎯 Тестирование жестов

### Свайп-навигация на странице товара:
1. Откройте любой товар с несколькими фото
2. **Свайп влево** → следующее изображение
3. **Свайп вправо** → предыдущее изображение
4. **Тап по точкам** → переход к конкретному изображению

### Мобильное меню:
1. Тап по гамбургеру → меню открывается
2. Тап по крестику → меню закрывается
3. Тап вне меню → меню закрывается

## ⚡ Тестирование производительности

### В браузере:
1. Откройте DevTools (F12)
2. Перейдите на вкладку "Lighthouse"
3. Выберите "Mobile" и "Performance"
4. Нажмите "Generate report"

### Целевые показатели:
- **First Contentful Paint**: < 1.5s
- **Largest Contentful Paint**: < 2.5s
- **Cumulative Layout Shift**: < 0.1
- **First Input Delay**: < 100ms

## 🐛 Частые проблемы и решения

### Проблема: Свайпы не работают
**Решение**: Убедитесь, что JavaScript включен и страница полностью загружена

### Проблема: Меню не открывается
**Решение**: Проверьте консоль браузера на ошибки JavaScript

### Проблема: Изображения не загружаются
**Решение**: Проверьте, что сервер запущен и файлы изображений существуют

### Проблема: Медленная загрузка
**Решение**: Проверьте размеры изображений и оптимизируйте их
